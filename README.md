# متجر مشكاة (Mishkat)

متجر إلكتروني عربي (RTL) لعلامة **مشكاة** ومنتجها **سبيلي**. يشمل كتالوج المنتجات، وسلة مشتريات، وإتمام الطلب بـ**الدفع عند الاستلام فقط**، وحفظًا دائمًا للطلبات، ولوحة تحكم لعدة مسؤولين.

## التقنيات المستعملة ولماذا

| التقنية | السبب |
|---|---|
| **Next.js 16 + React 19 + TypeScript** | صفحات سريعة ومهيّأة لمحركات البحث، والواجهة والخادم في مشروع واحد |
| **Tailwind CSS 4** | نظام تصميم موحّد يدعم RTL |
| **SQLite / Turso (libSQL) + Drizzle ORM** | قاعدة بيانات حقيقية: ملف محلي أثناء التطوير، و Turso (مجاني) في الإنتاج بنفس الكود |
| **Vercel + Vercel Blob** | استضافة مجانية للمشاريع الصغيرة، وتخزين لصور المنتجات التي تُرفع من لوحة التحكم |

التكلفة المتوقعة: **0 د.ت شهريًا** في الخطط المجانية، إضافة إلى ثمن اسم النطاق (الدومين) فقط.

## 1. التشغيل على جهازك

المتطلبات: Node.js 20.9 أو أحدث.

```bash
npm install
```

```bash
npm run setup
```

ينشئ هذا الأمر قاعدة البيانات المحلية `data/mishkat.db` ويضيف إليها لعبة سبيلي والآراء.

أنشئ ملف `.env.local` بالاعتماد على `.env.example`، وضع فيه قيمة `AUTH_SECRET`. لتوليد قيمة عشوائية:

```bash
node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"
```

أنشئ حسابك في لوحة التحكم:

```bash
npm run admin:create -- "اسمك" you@example.com "كلمة-سر-قوية-10-أحرف-على-الأقل"
```

ثم شغّل الموقع:

```bash
npm run dev
```

- المتجر: http://localhost:3000
- لوحة التحكم: http://localhost:3000/admin

## 2. أوامر مفيدة

| الأمر | الوظيفة |
|---|---|
| `npm run dev` | تشغيل الموقع للتطوير |
| `npm run build` ثم `npm start` | نسخة الإنتاج |
| `npm test` | الاختبارات الآلية (الطلبات، المخزون، التحقق من البيانات) |
| `npm run db:migrate` | تطبيق تحديثات قاعدة البيانات |

| `npm run assets` | إعادة تجهيز الصور من الملفات الأصلية |
| `npm run db:studio` | تصفّح قاعدة البيانات في المتصفح |

## 3. النشر على الإنترنت (Vercel + Turso)

كل عملية نشر تجهّز قاعدة البيانات تلقائيًا (`scripts/prepare-db.ts`):
- تطبّق تحديثات الجداول.
- تضيف سبيلي والآراء إن لم تكن موجودة، ولا تغيّر أي تعديل قمت به.
- تنشئ أول حساب في لوحة التحكم.

لا تحتاج تشغيل أي أمر من جهازك.

1. على [vercel.com](https://vercel.com) سجّل الدخول بحساب GitHub، ثم **Add New → Project** واختر المستودع `mishkat-website` ثم **Import**. لا تضغط Deploy بعد.
2. في **Environment Variables** أضف:
   - `AUTH_SECRET`: قيمة عشوائية طويلة (32 حرفًا على الأقل).
   - `INITIAL_ADMIN_NAME` و `INITIAL_ADMIN_EMAIL` و `INITIAL_ADMIN_PASSWORD`: بيانات أول حساب في لوحة التحكم (كلمة سر من 10 أحرف على الأقل).
3. اضغط **Deploy**. ستفشل أول محاولة برسالة «No database configured»، وهذا متوقع.
4. من تبويب **Storage** في المشروع:
   - **Create Database → Turso**: اختر منطقة أوروبية قريبة من تونس (Frankfurt أو Paris) واربطها بالمشروع. يضيف `TURSO_DATABASE_URL` و `TURSO_AUTH_TOKEN` تلقائيًا.
   - **Create → Blob** واربطه بالمشروع. يضيف `BLOB_READ_WRITE_TOKEN`، وبدونه لا يعمل رفع الصور من لوحة التحكم.
5. من **Deployments** اضغط **Redeploy**. بعد النجاح افتح `/admin` وادخل بالحساب الذي وضعته، ثم غيّر كلمة السر من صفحة «المسؤولون». يمكنك بعدها حذف متغيرات `INITIAL_ADMIN_*`.

أي تعديل ترفعه إلى GitHub بعد ذلك يُنشر تلقائيًا.

> بديل لربط Turso من Vercel: أنشئ القاعدة على [turso.tech](https://turso.tech) وضع `DATABASE_URL` و `DATABASE_AUTH_TOKEN` يدويًا في Environment Variables.

### اسم النطاق
من **Settings → Domains** في Vercel أضف نطاقك (مثل `.tn` أو `.com`)، واتبع تعليمات DNS. بعدها ضع `NEXT_PUBLIC_SITE_URL` (مثل `https://mishkat.tn`) وأعد النشر.

## 4. الاستعمال اليومي (لوحة التحكم)

- **الطلبات:** كل طلب جديد يظهر بحالة «طلب جديد». افتحه، واتصل بالزبون أو راسله على واتساب بزر واحد، ثم غيّر الحالة: تم تأكيد الطلب ← قيد التجهيز ← تم الشحن ← تم التسليم.
- **الإلغاء:** يُرجع الكميات إلى المخزون تلقائيًا.
- **المنتجات:** أضف منتجًا جديدًا، أو عدّل السعر والسعر قبل التخفيض والمخزون، وارفع الصور ورتّبها. لا حاجة لتعديل الكود.
- **الإعدادات والمحتوى:** مصاريف ومدة التوصيل، أرقام التواصل، الروابط، نصوص السياسات، الأسئلة الشائعة، والآراء.
- **المسؤولون:** أضف حسابات جديدة، أو أوقف حسابًا (يخرج صاحبه فورًا)، أو غيّر كلمة سرك.

## 5. الحماية والموثوقية

- **الدفع:** عند الاستلام فقط. لا توجد أي حقول لبطاقات بنكية ولا ربط ببوابات دفع.
- **الأسعار:** تُعاد حسابها على الخادم من قاعدة البيانات، ولا يُعتمد على ما يرسله المتصفح.
- **عدم تكرار الطلب:** كل عملية إتمام طلب تحمل مفتاحًا فريدًا. الضغط مرتين أو إعادة الإرسال بعد انقطاع الإنترنت يعطي نفس الطلب ولا يُنشئ طلبًا ثانيًا (توجد اختبارات لذلك).
- **المخزون:** يُنقص داخل نفس عملية الحفظ، فلا يُباع أكثر من المتوفر.
- **صفحة التأكيد:** لا تظهر إلا بعد حفظ الطلب فعليًا، وتُفتح برابط سرّي لا يمكن تخمينه.
- **لوحة التحكم:** كلمات سر مشفّرة (bcrypt)، وجلسات موقّعة في كوكي `httpOnly`، وحدّ لمحاولات الدخول، وكل عملية في اللوحة تتحقق من الجلسة من جديد.
- **محركات البحث:** صفحات السلة والطلب ولوحة التحكم لا تظهر فيها.

## 6. إضافة الفرنسية لاحقًا

كل نصوص الواجهة في `src/i18n/ar.ts`. لإضافة الفرنسية:
1. أنشئ `src/i18n/fr.ts` بنفس المفاتيح.
2. أضفها في `src/i18n/config.ts`.
3. أضف مسارات باللغة.

## 7. هيكل المشروع

```
src/
  app/(store)/      صفحات المتجر (الرئيسية، المتجر، المنتج، السلة، الطلب...)
  app/admin/        لوحة التحكم + server actions
  app/actions/      إرسال الطلب من المتجر
  components/       مكوّنات الواجهة (store / admin / ui / brand)
  db/               مخطط قاعدة البيانات والبيانات الأولية
  server/           منطق الطلبات، المصادقة، الإعدادات، رفع الصور
  lib/              أدوات: الأسعار، الهاتف التونسي، التحقق، السلة
  i18n/             النصوص العربية
design-system/      مرجع الهوية البصرية
scripts/            تجهيز الصور، قاعدة البيانات، إنشاء المسؤول
tests/              الاختبارات الآلية
```
